Quizandar Portable
==================

Портативная версия викторины Quizandar. Не требует установки Java,
Docker или других зависимостей — всё нужное лежит рядом в папке.

Как запустить
-------------

1. Убедитесь, что в папке 'questions' лежат JSON-файлы с вопросами.
   Один файл — одна тема (например, «Советские мультфильмы», «Английский A1»).

2. Запустите start.bat (двойной клик).

3. Скрипт определит ваш локальный IP-адрес, выведет его в консоль
   и через несколько секунд откроет в браузере страницу ведущего.
   Также в консоли будет адрес для игроков — его можно отправить
   в мессенджере или использовать QR-код со страницы ведущего.

4. Игроки подключаются по адресу вида:
      http://192.168.x.x:8080/#/player

Как остановить
--------------

Закрывайте приложение через Ctrl+C в окне консоли — так Java-процесс
корректно завершится. Если просто закрыть окно крестиком, процесс
может остаться в фоне и занять порт 8080.

Как добавить новые вопросы
--------------------------

Просто положите JSON-файл в папку 'questions'. Формат файла:

{
  "title": "Название темы",
  "description": "Краткое описание",
  "questions": [
    {
      "id": "q1",
      "text": "Текст вопроса?",
      "type": "SINGLE",
      "timeLimitSec": 10,
      "options": [
        { "id": "a", "text": "Вариант 1" },
        { "id": "b", "text": "Вариант 2" },
        { "id": "c", "text": "Вариант 3" },
        { "id": "d", "text": "Вариант 4" }
      ],
      "correctOptionIds": ["b"]
    }
  ]
}

После добавления файла перезапустите приложение (или обновите
страницу ведущего — список тем подгружается заново).

Возможные проблемы
------------------

- Порт 8080 занят: закройте другое приложение, использующее этот порт,
  либо завершите старый процесс Java через диспетчер задач.

- Windows Firewall спрашивает разрешение при первом запуске — разрешите
  доступ, иначе игроки не смогут подключиться по сети.

- Если страница не открылась автоматически, откройте вручную адрес,
  показанный в консоли (Host page).

Приятной игры!
