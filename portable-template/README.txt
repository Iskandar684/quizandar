Quizandar Portable
==================

Как запустить
-------------
Двойной клик по ярлыку «Запустить Quizandar» (зелёная иконка).
Скрипт определит ваш IP, выведет адрес в консоль и откроет браузер.

Как остановить
--------------
Двойной клик по ярлыку «Остановить Quizandar» (красная иконка).

Как добавить вопросы
--------------------
Положите JSON-файл в папку 'questions'. Один файл — одна тема.
После добавления перезапустите приложение.

Структура
---------
questions/            — ваши файлы с вопросами
Запустить Quizandar.lnk
Остановить Quizandar.lnk
app/                  — служебные файлы, не трогать
    jre/              — Java
    quizandar.jar     — приложение
    start.bat, stop.bat, make-shortcuts.bat
    icons/

Если ярлыки не работают
-----------------------
Значит, папка была перемещена после сборки (ярлыки хранят абсолютные пути).
Удалите старые ярлыки и запустите app\make-shortcuts.bat — ярлыки создадутся заново.

Порт: 8765. Если занят, измените --server.port в app\start.bat и порт в app\stop.bat.
