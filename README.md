# 🎯 Quizandar

**Quizandar** — интерактивная викторина с подключением по QR-коду.  
Игроки сканируют QR-код, вводят имя и соревнуются в скорости и точности ответов.  
За правильные и быстрые ответы начисляются баллы, после каждого вопроса показывается живая таблица лидеров.  

Проект создан для изучения полного цикла full‑stack разработки: от real‑time взаимодействия на WebSocket до реактивного фронтенда.  
Идеально подходит для портфолио и демонстрации на аттестации.

---

## 📌 Идея и геймплей

1. На главном экране (ведущего) появляется QR-код.
2. Игроки сканируют его телефонами, открывают веб-страницу и вводят имя.
3. Ведущий запускает вопрос с вариантами ответов.
4. Игроки выбирают ответ; учитывается **правильность** и **время ответа**.
5. Когда все ответили (или вышло время), на экране ведущего отображается сводка: кто первым ответил правильно, кто вторым и так далее.
6. Игра продолжается следующим вопросом.
